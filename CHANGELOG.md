# Changelog

## 0.1.0 — 2026-10-05

Initial semantic foundation.

- Modern TypeScript representation of the classical JavaScript transducer protocol.
- Explicit `*T` transducer API.
- Sync Iterable and AsyncIterable adapters.
- RxJS 7.8.2 adapter.
- `Reduced` propagation and early-cancellation tests.
- Documentation of the boundary between generic transduction and reactive orchestration.
